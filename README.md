# Real-Time Face Recognition with MTCNN + ResNet50 + Telegram Notifications

This project uses **MTCNN** and **ResNet50 embeddings** to detect faces in real-time from a webcam. When an **unknown person** is detected, a **Telegram notification** is sent instantly to your phone.

---

## Features

- Real-time webcam face detection.
- Recognizes known faces using ResNet50 embeddings.
- Sends Telegram notifications for unknown visitors.
- Handles multiple faces in a single frame.
- Cooldown mechanism to prevent notification spam.

---

## Note : You have to make your own bot, own chatid, and self bot token
